# 📦 Proyecto – Rama `develop`

Este archivo **README.md** corresponde a la rama **`develop`** de este repositorio.  
En esta rama se realizan las tareas de **desarrollo activo**, pruebas y nuevas implementaciones antes de ser integradas en la rama principal (`main` o `master`).

---

## 🚀 Propósito de la rama `develop`

La rama **develop** sirve como entorno de integración donde se fusionan las características en desarrollo.  
Aquí se prueban nuevas funcionalidades, se corrigen errores y se preparan versiones previas a producción.

---

## 🌿 Ramas derivadas de `develop`

Las siguientes ramas **heredan directamente de `develop`** y se utilizan para gestionar distintas fases o módulos del proyecto:

- `H1` → Desarrollo de la Historia de Usuario 1.  
- `H2` → Desarrollo de la Historia de Usuario 2.  
- `H3` → Desarrollo de la Historia de Usuario 3.  
- `H4` → Desarrollo de la Historia de Usuario 4.

Cada una de estas ramas se mantiene sincronizada con `develop` y, una vez completadas sus tareas, pueden fusionarse nuevamente en esta rama para integrar los avances.

---

## 🧩 Flujo de trabajo (Git Flow adaptado)

1. **main / master** → Rama estable, contiene el código listo para producción.  
2. **develop** → Rama de desarrollo activo.  
3. **H1 - H4** → Ramas derivadas de `develop` para desarrollo de módulos o tareas específicas.

---

## 💡 Recomendaciones

- No realizar *commits* directamente en `main`.
- Mantener las ramas `H1` a `H4` actualizadas con `develop`.  
- Realizar *pull requests* desde las ramas `H1` a `H4` hacia `develop` una vez completadas las tareas.  
- Probar y revisar el código antes de integrar cambios en `develop`.
